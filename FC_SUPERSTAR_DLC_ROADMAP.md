## 🎯 DLC-A : LE MERCATO

**Contexte** : Ton agent veut renégocier ton contrat. Trois chemins s'ouvrent.

### Route A1 : "Le Loyal" (Rester)
```
Jour 4 : Agent te contacte
├─ Scène: "Tu as impressionné le staff"
├─ Notif: Marco (Agent) → "Contrat pro ? On peut l'avoir"
└─ Choix: Écouter / Refuser / Négocier

Jour 5 : Réunion avec Direction
├─ Scène: "Bureau du club, tension"
├─ Stats delta: +10 confiance, +5000€, +3 réputation
└─ Notif: Club → "Contrat 2 ans signé ✅"

Jour 6 : Réaction coéquipiers
├─ Scène: "Vestiaire : jalousie des anciens"
├─ Stats delta: -5 mental, +2 relation allié
└─ Choix: Humble / Arrogant / Ignorant

FIN A1 : "Le Titulaire" 
└─ Bonus: +15% temps de jeu à venir
```

### Route A2 : "L'Ambitieux" (Partir)
```
Jour 4 : Fabrizio Romano tweet
├─ Notif: 🗞️ "Grand club surveille ce talent"
├─ Scène: "Appel de Marco : offre à 12k€/mois"
└─ Choix: Accepter / Refuser / Jouer double jeu

Jour 5 : Conflit avec direction
├─ Scène: "Réunion tendue : on refuse de vendre"
├─ Stats delta: -8 mental, +10 confiance
└─ Notif: Marco → "Laisse-moi faire, on les force"

Jour 6 : Transfert acté
├─ Scène: "Valise faite, nouveau club"
├─ Stats delta: +12000€, +5 media, -3 relation vestiaire
└─ Choix: Dire au revoir / Partir sans prévenir / Merci sincère

FIN A2 : "L'Ambitieux" 
└─ Bonus: +20% salaire, -30% relation anciens coéquipiers
```

### Route A3 : "Le Rebelle" (Rupture Agent)
```
Jour 4 : Marco veut renégocier
├─ Scène: "Agent veut sa commission"
├─ Notif: Marco → "Je t'ai porté, maintenant tu me dois"
└─ Choix: Accepter / Refuse secrètement / Confrontation

Jour 5 : Rupture avec agent
├─ Scène: "Conflit violent : Marco te menace"
├─ Stats delta: -10 mental, -5000€, -5 relation Marco
└─ Notif: Marco → "Tu le regretteras..."

Jour 6 : Conséquences
├─ Scène: "Seul(e) face aux négociations"
├─ Stats delta: +8 confiance, -3 support
└─ Choix: Négocier seul / Trouver un nouveau agent / Partir en Free

FIN A3 : "L'Indépendant" 
└─ Malus: Marco peut revenir créer du chaos, mais +5% liberté
```

## 🎯 DLC-B : LE VESTIAIRE

**Contexte** : Un coéquipier devient capitaine. Tu dois choisir ton attitude.

### Route B1 : "Le Leader" (Prendre le Pouvoir)
```
Jour 4 : Capitaine titre se blesse
├─ Scène: "Match : collision grave"
├─ Notif: Club → "Recherche nouveau capitaine temporaire"
└─ Choix: Te proposer / Laisser faire / Soutenir autre

Jour 5 : Election informelle du vestiaire
├─ Scène: "Vestiaire : vote sur le capitaine"
├─ Stats delta: +15 confiance, +8 leadership, -2 relation rivaux
└─ Notif: Coéquipiers → "On te choisit !"

Jour 6 : Responsabilités & Risques
├─ Scène: "Match difficile : tu dois motiver"
├─ Stats delta: +10 mental, -5 energy, +5 media
└─ Choix: Parole de leader / Laisser coach / Action physique

Jour 7 : Victoire ou Défaite Leadership
├─ Si victoire: +20 reputation, +10 confiance
└─ Si défaite: -10 reputation, -8 confiance

FIN B1 : "Le Capitaine" 
└─ Bonus: Leadership actif, vestiaire te suit, mais pression accrue
```

### Route B2 : "L'Invisible" (Rester Discret)
```
Jour 4 : Capitaine se blesse
├─ Scène: "Tu restes silencieux"
├─ Notif: Coach → "Et toi, tu dis rien ?"
└─ Choix: Parler / Rester muet / Soutenir un autre

Jour 5 : Quelqu'un d'autre devient capitaine
├─ Scène: "Vestiaire : leadership alternatif"
├─ Stats delta: +3 mental, -2 confiance, +3 mental
└─ Notif: Nouveau capitaine → "On compte sur toi en silence"

Jour 6 : Liberté & Absence de Pression
├─ Scène: "Match sans pression de leadership"
├─ Stats delta: +8 energy, +5 focus
└─ Choix: Exceller / Rester dans l'ombre / Observer

Jour 7 : Respect discret
├─ Scène: "Coach te parle en privé"
├─ Stats delta: +6 reputation (auprès du staff), +4 mental
└─ Notif: Coach → "T'es discret, mais tu joues bien"

FIN B2 : "Le Discret" 
└─ Bonus: Moins de pression, +10% performance sous stress, réputation calme
```

### Route B3 : "Le Provocateur" (Créer la Tension)
```
Jour 4 : Capitaine se blesse
├─ Scène: "Tu contestes la hiérarchie"
├─ Notif: Toi → "Je suis meilleur que lui"
└─ Choix: Provocation directe / Manœuvre sournoise / Compétition ouverte

Jour 5 : Conflit vestiaire
├─ Scène: "Tension monte entre factions"
├─ Stats delta: +12 confiance, -8 mental, -3 relation allié
└─ Notif: Ancien capitaine → "Attention, tu vas trop loin"

Jour 6 : Match tendu
├─ Scène: "On se regarde en travers sur le terrain"
├─ Stats delta: +10 energy (adrenaline), -5 mental
└─ Choix: Escalade / Réconciliation / Domination sur le pitch

Jour 7 : Résolution Violente ou Apaisement
├─ Si escalade: -15 reputation, +10 confiance, vestiaire divisé
└─ Si apaisement: +5 reputation, +8 mental

FIN B3 : "Le Provocateur" 
└─ Malus/Bonus: Vestiaire divisé, mais performance élevée, risque de sanctions
```

## 🎯 DLC-C : LES MÉDIAS & IMAGE

**Contexte** : Les réseaux parlent de toi. Comment gères-tu ton image ?

### Route C1 : "Le Communicant" (Maîtriser Image)
```
Jour 4 : Boom de médias après match impressionnant
├─ Notif: Instagram → "+50k followers en 1 jour !"
├─ Notif: Presse → "Interview demandée"
└─ Choix: Accepter / Refuser / Négocier sponsoring

Jour 5 : Interview TV + Post Instagram stratégique
├─ Scène: "Studio TV : tu parles du projet du club"
├─ Stats delta: +15 media, +8 confiance, +2000€ sponsoring
└─ Notif: Sponsor Nike → "On veut te signer"

Jour 6 : Contrat sponsoring
├─ Scène: "Négociation Nike/Adidas"
├─ Stats delta: +5000€/mois sponsoring, +10 media, +3 reputation
└─ Choix: Nike / Adidas / Puma / Refuser tous

Jour 7 : Conséquences positives
├─ Scène: "Vestiaire : jalousie discrète mais tu es bankable"
├─ Stats delta: +3000€ bonus, +5 media cote
└─ Notif: Marque → "Contrat exclusif à renouveler"

FIN C1 : "La Marque Vivante" 
└─ Bonus: +50% revenus sponsoring, cote médias +20%, risque: critique si sous-performance
```

### Route C2 : "Le Silencieux" (Éviter Scandale)
```
Jour 4 : Buzz média après match
├─ Notif: 🗞️ "Rumeur : contrat en négociation"
├─ Scène: "Journaliste t'attend à la sortie"
└─ Choix: Parler / Éviter / Agresser verbalement

Jour 5 : Refus de parler aux médias
├─ Scène: "Tu ignores les demandes d'interview"
├─ Stats delta: +5 mental (paix), -2 media, +3 reputation (sobre)
└─ Notif: Coach → "Bonne stratégie, focus sur le terrain"

Jour 6 : Tranquillité & Moins de Distractions
├─ Scène: "Entraînement calme, pas de caméra"
├─ Stats delta: +8 energy, +6 mental, +4 focus
└─ Choix: Continuer silence / Parler une fois / Ouvrir profile

Jour 7 : Mystère autour de toi
├─ Scène: "Vestiaire : on te respecte pour ta discrétion"
├─ Stats delta: +5 reputation, +3 mental, -1 media
└─ Notif: Coach privé → "Tu deviens un leader silencieux"

FIN C2 : "L'Ombre du Terrain" 
└─ Bonus: -80% distractions médias, stabilité mentale +25%, cote public basse mais respectée
```

### Route C3 : "Le Provocateur" (Faire le Buzz)
```
Jour 4 : Boom média post-match
├─ Notif: Twitter → "Ton tweet : 'Je vais tous les détruire'"
├─ Scène: "C'est viral en 2h"
└─ Choix: Doubler down / Modérer / Supprimer

Jour 5 : Buzz intentionnel & Controverse
├─ Scène: "Interview trash : tu clashes les rivaux"
├─ Stats delta: +20 media, +12 confiance, -8 mental (stress), -3 relation staff
└─ Notif: Club → "On parle de toi, mais gère !"

Jour 6 : Conséquences du Buzz
├─ Scène: "Fans contre toi, rivalité intense"
├─ Stats delta: +15 energy (adrénaline match), -10 mental, +10 media (viral)
└─ Choix: Continuer / Calmer / Escalader

Jour 7 : Résolution du Drama
├─ Si tu domines: +15 reputation (parmi fans), +20 media, but mémorable
└─ Si tu échoues: -12 reputation, critique médias, mais culte chez rivalité

FIN C3 : "Le Bad Boy de la Ligue" 
└─ Bonus/Malus: Cote médias explosive, transferts plus lucratifs, mais risque sanctions + contrats perdus
```

## 🎯 DLC-D : L'HÉRITAGE (Post-Saison)

**Contexte** : Fin de saison. Tu décides du destin de ta carrière.

### Route D1 : "La Légende" (Gloire Finale)
```
Jour 11 : Dernière ligne droite de saison
├─ Scène: "Tu es en course pour le titre"
├─ Stats: Energy 85, Mental 80, Confidence 90
└─ Notif: Club → "Déjà 15 buts, 8 passes cette saison!"

Jour 12 : Match décisif pour le titre
├─ Scène: "Stade plein, 2-2 à la 85e"
├─ Choix: Tenter un coup de génie / Jouer safe / Assist ton coéquipier
└─ Si génie: But mémorable, légende

Jour 13 : Titre Gagné
├─ Scène: "Toi et tes coéquipiers soulevez le trophée"
├─ Stats delta: +30 reputation, +50000€ bonus, +20 media
└─ Notif: Tous les medias → "LÉGENDE DU CLUB"

Jour 14 : Contrat de rêve
├─ Scène: "3 grands clubs te font des offres"
├─ Choix: Rester en légende / Partir en gloire / Nouvelle aventure
└─ Effet: Choisir ton avenir

Jour 15 : Bilan de carrière
├─ Scène: "Rétrospective : ta saison en images"
├─ Stats: Reputation 95, Media 92, Money 450000€
└─ Ending Screen: "TU ES UNE LÉGENDE. BIENVENUE DANS L'HISTOIRE."

FIN D1 : "La Légende" ⭐⭐⭐⭐⭐
└─ Débloque: Content bonus "La Retraite Dorée"
```

### Route D2 : "Le Retour" (Boucle Fermée)
```
Jour 11 : Fin de saison correcte (pas titre, pas catastrophe)
├─ Scène: "Tu as atteint ton objectif personnel"
├─ Stats: Energy 65, Mental 75, Confidence 70
└─ Notif: Agent → "Propositions variées pour la suite"

Jour 12 : Appel du club natal
├─ Scène: "Ton club de jeunesse te contacte"
├─ Choix: Retour / Rester / Ailleurs
└─ Notif: Karim (allié) → "Reviens avec moi chez nous"

Jour 13 : Retour Émotionnel
├─ Scène: "Tu revois le stade où tu as grandi"
├─ Stats delta: +15 mental (nostalgie), +8 reputation, +2000€
└─ Conférence: "C'est ici que tout a commencé"

Jour 14 : Reconstruction
├─ Scène: "Tu entraines les jeunes du club natal"
├─ Choix: Groomer une nouvelle génération / Jouer encore / Devenir scout
└─ Effet: Choix de l'après

Jour 15 : Bilan & Héritage
├─ Scène: "Ta statue se dresse au stade"
├─ Stats: Reputation 78, Legacy 95, Money 280000€
└─ Ending Screen: "TU AS FERME LA BOUCLE. L'HÉRITAGE CONTINUE."

FIN D2 : "Le Retour" ⭐⭐⭐⭐
└─ Débloque: Content bonus "Génération Nouvelle"
```

### Route D3 : "La Retraite" (Fin Anticipée)
```
Jour 11 : Réalisation personnelle
├─ Scène: "Tu as atteint tes objectifs, tu es fatigué"

Jour 14 : Nouvelle Vie
```
